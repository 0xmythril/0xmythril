# Cham Ho — 0xMythril

**Product Lead at [Moca Network](https://moca.network) (Animoca Brands), building Agentic Identity via [AIR](https://air3.com).**

An AI agent acting on your behalf has to prove two things: who it acts for, and what it's allowed to do. Almost every agent demo today either hands over a raw key or stays read-only — neither scales. I work on the third option: an agent with its own credential and its own scoped, revocable authority over your account, so it can transact, prove a membership it inherited from somewhere else, and be audited afterwards.

Most of that ships closed. What's public is below.

## 📐 How I build

- **Design for problems & outcomes** — outputs only matter when they move something.
- **Learn from proven patterns** — reuse what works, save the effort for what differentiates.
- **Ship first, learn fast** — iteration reveals reality faster than planning does.
- **Simple is best** — if it needs a manual, it isn't done.
- **Build only with demand signals** — commit real resources when users commit something too.
