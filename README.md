## 📐 Product Principles

- **Design for problems & outcomes** — Outputs only matter when they move user or business outcomes.
- **Learn from proven patterns** — Reuse what works, save effort for differentiation.
- **Ship first, learn fast** — Iteration reveals reality faster than planning.
- **Simple is best** — Reduce cognitive load. If it needs a manual, it isn't done.
- **Build only with demand signals** — Commit real resources when users commit something too.
